# Third-party references

TouchBarChat's Touch Bar integration was informed by the following MIT-licensed projects:

- [ClaudeBar](https://github.com/TouchMyBar/claudebar)
- [CodexBar](https://github.com/wjx8/CodexBar)
- [MTMR](https://github.com/Toxblh/MTMR)

TouchBarChat currently links no third-party package. Its audio, speech and sound-classification components use Apple frameworks. Preserve relevant license and copyright notices if source code is copied from the projects above in a future revision.
